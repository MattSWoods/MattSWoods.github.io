# Weekly Cleaning Checklist

Check off as you go. Daily tasks = every day. Weekly tasks = spread across the week.

---

## Daily — ~15–20 min total

| Kitchen | Living & dining | Bathrooms | General |
|---|---|---|---|
| ☐ Wipe counters & stovetop | ☐ Spot-tidy surfaces | ☐ Wipe sink(s) | ☐ Put things back in place |
| ☐ Dishes / dishwasher | ☐ Clear table after meals | ☐ Toilet swish if needed | ☐ Tidy entryways |
| ☐ Wipe sink | | | |

---

## Weekly — Spread across the week, 1–2 rooms per day

| Kitchen | Guest bathroom | Main bathroom | Living & dining |
|---|---|---|---|
| ☐ Sweep & mop floor | ☐ Clean toilet | ☐ Clean toilet | ☐ Vacuum furniture |
| ☐ Wipe cabinet fronts | ☐ Scrub sink & vanity | ☐ Scrub both sinks & vanity | ☐ Vacuum/sweep floors |
| ☐ Wipe out microwave | ☐ Wipe mirror | ☐ Wipe both mirrors | ☐ Wipe surfaces & table |
| ☐ Empty trash | ☐ Sweep & mop floor | ☐ Sweep & mop floor | ☐ Dust flat surfaces |
| | ☐ Wipe shower/tub | ☐ Wipe shower/tub | |

| Family room | Home offices (both) | Main bedroom | Guest/storage/utility |
|---|---|---|---|
| ☐ Vacuum floors & furniture | ☐ Vacuum/sweep floors | ☐ Change sheets (every 1–2 wks) | ☐ Quick vacuum as needed |
| ☐ Wipe hard surfaces | ☐ Wipe desks & surfaces | ☐ Vacuum floor | ☐ No full clean required |
| ☐ Spot tidy | ☐ Empty trash | ☐ Wipe nightstands | |

---

> **Spiral-breaker:** If you spot something deep-clean-worthy, write it on the deep clean list and keep going. It has a place — just not today.

# Deep Clean Rotation

One task per week. Pick it, do it, check it off. That's all.

---

### Kitchen — *Every 4–6 weeks per task*

| | |
|---|---|
| ☐ Inside of oven | ☐ Range hood & filter |
| ☐ Inside of fridge (shelves & drawers) | ☐ Inside cabinets & pantry |
| ☐ Behind/under appliances | ☐ Descale coffee maker |

### Bathrooms — *Monthly or as needed*

| | |
|---|---|
| ☐ Scrub grout | ☐ Wipe baseboards |
| ☐ Descale shower head | ☐ Wash bath mats |
| ☐ Deep clean toilet tank | ☐ Clean exhaust fan cover |

### Windows & glass — *Seasonally*

| | |
|---|---|
| ☐ Inside window glass | ☐ Sliding door tracks |
| ☐ Window sills & tracks | ☐ Full mirror wipe-down |

### Whole house — *Quarterly*

| | |
|---|---|
| ☐ Baseboards throughout | ☐ Ceiling fans |
| ☐ Light switches & door handles | ☐ Vents & returns |
| ☐ Door frames & molding | ☐ Behind & under furniture |

### Bedrooms — *Seasonally*

| | |
|---|---|
| ☐ Wash pillows & duvet inserts | ☐ Vacuum under bed |
| ☐ Rotate/flip mattress | ☐ Wipe furniture (incl. undersides) |

### Home gym & utility — *Quarterly or as needed*

| | |
|---|---|
| ☐ Sweep/vacuum floors | ☐ Declutter/organize storage |
| ☐ Wipe down equipment | |

---

> **Reminder:** Deep cleaning is a separate project from routine cleaning. When you're doing daily or weekly tasks, this list doesn't exist.
